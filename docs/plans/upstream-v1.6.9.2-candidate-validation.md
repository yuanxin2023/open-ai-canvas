## 真实数据发现与处理

启动时发现旧官方 `yingce-image-*` 与本地三个图片 ID 并存，且旧图层拆分已有安装关系。保护检查先停止启动，用户明确选择保留两套已有 ID、全部历史版本和原安装关系。旧官方三项保留历史内容、不再自动目录更新；本地三个主身份继续更新，Schema 仍为 83。身份、版本归属、安装、包路径和归档完整性校验继续保留；不删除、改名、合并或复活旧记录。详见[CAN-05a 决策](upstream-v1.6.9.2-skill-identities.md)。

本机既有库升级已经实际执行；切换旧代码不能代替数据库回退。升级前完整备份及校验清单保存在 Git 忽略的本地备份目录，精确路径见本地 `confirmed-business-backup.json`。恢复须先停止候选服务，按备份恢复数据库和相应数据目录，并明确处理升级后的新增写入。
