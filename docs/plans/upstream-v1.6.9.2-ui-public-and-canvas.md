# 公共页面、画布与模型调价补充决策

本记录补充 UI-03、UI-04、CAN-11、CAN-12、PLG-07 的确认与实施过程。候选代码位于独立工作树；用户后续已明确允许本机现有库升级与预览，当前结果以[候选验收记录](upstream-v1.6.9.2-candidate-validation.md)为准，下文较早阶段状态仅供追溯。

## UI-03：自定义公告

- 调用链：外观配置及资源校验 → appearance API/store → 现有更新日志按钮与后台公告编辑器。
- 冲突：官方新增自定义文字、图片、视频公告；本地保留品牌、Glow、原日志入口和购买流程。
- 选择：用户确认接入可选公告，默认关闭，由用户主动查看。已有外观字段保留；读取旧配置不写回，旧品牌识别边界不随合同 14 改动。
- 数据与权限：沿用站点外观权限和资源归属检查，不恢复皮肤、欢迎页或外部购买地址。软件更新另走自有正式 Release。
- 验证：外观默认、旧配置、权限与资源专项通过；公告相关前端 5 个测试文件共 32 项通过，另含真实日志入口隔离渲染 2 项。未做真实浏览器布局验收。

## UI-04：访客首页

- 调用链：路由 RequireAuth → 创作首页 → 普通生成、登录弹窗和 Agent 入口。
- 冲突：本地工作区先登录，官方允许访客浏览首页后登录生成。
- 选择：用户确认访客可进入 `/` 与 `/create`；生成前登录，其他私有路由仍需登录，原公开画布分享保留，欢迎页入口继续移除。
- 数据与权限：创作页按账号身份重新挂载；会话缓存继续使用用户作用域，过期异步结果不能写入另一账号。未登录启动 Agent 先提示登录，不创建画布或任务。
- 验证：真实 RequireAuth 和 Agent 入口的隔离 UI 检查覆盖首页放行、私有路径返回地址、会话未恢复、访客不创建任务、切换账号后迟到结果不跳转。相关前端 4 文件 5 项通过；普通生成与真实路由浏览器仍待联合验收。

## CAN-11：图层拆分连续执行

- 文件及调用链：CanvasNodeLayerDecompositionDialog → use-canvas-media-tools 的 planImageLayers/decomposeImageLayers → 后端文本规划任务与后续图片任务。
- 本地行为：直接提交图片拆分；官方行为：先用读图文本模型规划，再连续执行一个或多个拆图任务。
- 方案：分步确认两段费用；直接采用官方连续执行并先确认模型及计费说明；维持本地单次拆图。
- 最终决定：用户选择官方连续执行，开始前确认模型与计费说明。候选保留官方模型能力、原图比例、任务状态与结果验收；显示两段分别计费、数量依赖规划、失败或取消可能有已完成费用的说明，用户确认后才能开始。更换任一模型后重新确认。
- 数据与权限：不增加后台权限项；原归属、余额、用户配额与已确认结算规则继续约束每个任务。已有任务和输出不重算。
- 验证：实际拆层弹窗隔离渲染 2 项通过；规划、图层策略、透明度、输出状态、结果幂等与任务同步 7 文件 60 项通过。未调用真实付费模型，浏览器、完整连续任务与费用核对仍待验收。

## CAN-12：媒体调度

- 冲突：官方删除旧性能模式类型、持久偏好和顶部手动开关，采用新节点预算、LOD 与按需媒体加载；直接保留旧按钮会引用失效状态。
- 最终决定：用户确认采用新版调度并移除旧手动开关。保留本地积分浮层和站内购买，不修改画布内容，也不将旧浏览器偏好解释为新的渲染设置。
- 验证：待实际画布专项与浏览器缩放、平移、大图、音视频和恢复联合验收；不能只凭清除文本冲突判定通过。

## PLG-07：批量调价百分比

- 调用链：批量调价弹窗 → channel-model-pricing → 最终价格与版本快照请求 → 后端权限/事务保存。
- 冲突：本地按售价利润率，成本 100、输入 30% 得 142.86；官方按成本加价率，同样输入得 130。
- 最终决定：用户确认改用官方成本加价率，并明确更换计算、预览和文案。只作用于管理员主动预览并确认的新调价，不自动改现有价格、订单快照或账单；本地 0–2 位售价输入与最终 0.01 积分结算规则保留。
- 验证：计算采用整数精确四舍五入；覆盖无原地修改、独立 Token 价格、手工价格保存、范围、溢出及价格版本。最终前端整包与后台页面仍待验收。
