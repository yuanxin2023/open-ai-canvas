- 本地起点的 JSON 包含 105 个技能，另由 `builtinImageEditingSkillDefinitions` 增加 3 个 `open-ai-canvas-image-*` 技能，共 108 个内置身份。

- 本地 3 个图片技能对应官方 `yingce-image-editing`、`yingce-image-annotation`、`yingce-image-layer-split`。推荐本地既有 ID 继续作为主身份，如何处理已有官方 ID、包映射及预设引用另行确认，不默认为同名新建两套。

## 待讨论的实施合同

CAN-05/F-05b：官方新增 40 个 ID 中，3 个是已有图片能力。推荐保留本地 108 个身份，33 个相同 ID 的内容按版本更新且不覆盖用户副本；37 项新内容纳入可选目录但首次默认停用，由技能管理员审核后启用；3 个图片能力继续用本地 ID，包内和预设的引用同步映射，遇到已有官方身份数据先报告后确定映射。另一方案本轮只保留本地 108 个身份，推迟新增内容。

CAN-06/F-05c：推荐接入上列 8 个可选场景预设；浏览不安装，选用时列出技能及待安装项并经用户确认，只安装可见且可用的技能，不自动调用模型或改变权限/预算。缺失、停用或无权使用的项明确阻止并提示，不静默换技能或重启旧隐藏项。另一方案本轮暂不接入预设。

CAN-05 最终决定：**纳入新增内容，首次默认停用。**保留本地 108 个身份，37 项新内容进入可选目录；3 个图片能力保留本地 ID。同 ID 更新保留旧版本，保护用户副本、隐藏状态和安装关系。

CAN-05a：真实业务库发现三组已存在的官方/本地图片 ID，以及官方图层拆分上的一条安装关系。用户确认保留两套已有 ID 与安装，旧官方三项保留历史内容，不再纳入目录自动更新，不增加迁移号。已存在的同名条目暂时保留，不新建替代身份；详见[历史图片技能决策](upstream-v1.6.9.2-skill-identities.md)。

CAN-06 最终决定：**接入预设，确认后安装缺失技能。**浏览不安装；选用前列出全部技能和待安装项，停用/缺失/无权使用时阻止，不自动调用模型或改变预算。

## CAN-05 候选实现与来源核对

- 统一为 145 个目录包：本地 108 个身份与新增 37 项。补齐 72 条旧卡片的 `SKILL.md`；3 个图片技能正文与本地一致，只在结构化元数据中保留本地身份与中性作者名。第三方作者、来源和附件保持。
- 旧 domain JSON 的 105 项与图片定义均已有新源目录；旧 service JSON 是其中 33 项的完整子集，ID、正文及元数据均核对一致，不含额外内容。停止维护这两份重复 JSON 和旧图片 Go 定义，提交历史继续保留原始源。
- 新增 37 个包使用 `defaultDisabled: true`。只有首次新建技能身份时初始化停用；既有显式/隐式启用、隐藏、私有副本、安装/收藏/个人分类和旧标签不重置。现有源分类和排序不被目录刷新覆盖。
- 官方豆包音频提示词包原标记为用户自建来源（1），会绕过平台可用性；分发元数据已修正为平台来源（3），145 个目录包均经过来源核对。该修正不自动改写已有来源为用户自建的记录，仍先核对身份冲突。
- 启动同步在同一数据库事务内处理目录、版本和首次停用状态；旧记录尚无版本时，先保存旧正文的独立归档。失败回滚新数据并清理本次新写的归档；相同内容不新增版本或刷新更新时间。已删除的技能不复活。
- 若已有 `yingce-image-*` 的技能、版本、关系、可用性或墓碑记录，先明确报告待核对的身份映射，不自动改写。若稳定 ID 被用户自定义内容占用，同步拒绝覆盖。实际历史数据仍需副本检查，不假定不存在这些情况。
- 健康的用户 ZIP/GitHub 包不在启动刷新范围；损坏的完整包不退化成只含单个旧 instruction 的包。
- 固定基线记录于 `backend/internal/skills/testdata/builtin-merge-baseline.json`。实际源文件专项核对 145 个身份、75 份旧正文摘要及 37 个默认停用标记；`go test ./builtin` 完成嵌入包编译（无测试文件）。

## CAN-06 候选确认流程与验证

- 点击预设先读取全部技能的当前详情，校验身份、状态、版本和内容摘要；显示名称及待安装项，取消不会安装。
- 确认后重新读取每项，包括已安装项；内容版本变化、停用或无权访问时，在首次安装前拒绝。只安装当前缺失项，复核安装与最终技能库回执后才选用整组。
- 账号、画布或会话变化会关闭确认并停止剩余写入。重复确认有同步防重；失败不会宣称已选用整组，已成功的安装保留并明确提示重新检查。生成仍需单独提交，权限/审批/预算保持。
- 前端预设、源文件、分类 API、策展与缓存专项共 19 项、261 个断言通过。8 个相关 Go 文件已解析；事务、并发启动、撤权、身份冲突、旧版本读取与真实路由用例仍待 Linux/CGO 和数据库副本运行。完整 Agent 面板尚有恢复/形象交叉冲突，确认弹窗仅完成实际组件的局部渲染测试，未作浏览器验收。
