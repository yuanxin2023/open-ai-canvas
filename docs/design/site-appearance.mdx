# 站点及外观设计合同

## 1. 目标与边界

本模块让部署方在不修改源码的前提下管理站点身份、登录页内容、搜索摘要、版权与备案信息，以及 Canvas Agent 的名称、文案和头像。全站视觉固定使用项目内置的经典黑白样式，同时保留亮色与暗色模式，不提供运行时皮肤库或自定义主题协议。

技术兼容标识不属于品牌文案：仓库名、容器与升级器路径、剪贴板协议、localStorage key、插件 API version、数据库基线校验值和 User-Agent 可以继续使用 `open-ai-canvas` 或 `infinite-canvas`。英文品牌标识只用于新资源路径建议，不能自动改写已有对象存储前缀或历史资源。

## 2. 领域模型

| 分组 | 字段 | 行为 |
| --- | --- | --- |
| 品牌 | `brandName`、`brandSlug` | 展示名称进入页面、邮件、导出与诊断说明；slug 用于安全的路径建议 |
| Logo | 浅色 Logo、深色 Logo、外框开关 | 两套可独立上传；只有一套时双模式复用；关闭外框时在原占位内等比放大 |
| 登录页 | 主标题、说明、视频、封面 | 登录、注册与找回密码共用；自定义视频没有自定义封面时使用中性背景 |
| SEO | 标题、描述、关键词 | 标题和描述用于搜索摘要；关键词保留给其他搜索引擎或站内扩展 |
| 首页收尾 | 版权信息、备案开关、备案号 | 备案号仅在显式开启且非空时显示，并链接工信部备案系统 |
| 创作首屏 | 标题、模式、输入框和快捷建议区域的光晕开关、强度、颜色、大小与位置 | 仅生成低透明度径向光晕，不覆盖全站语义色、控件状态或主题 token |
| Canvas Agent | 助手名称、入口标签、面板标题、欢迎文案、输入提示、头像类型、高度、Live2D 资源 | Canvas 独立于站点品牌；Live2D 启用前由服务端校验资源归属和入口文件 |

配置继续存储在 `system_settings.appearance` JSON 中，schema version 为 13，不增加关系型数据库迁移。版本 8 删除旧的 `skinId`、`skinThemes` 和 `activeSkin` 合同；版本 9 新增独立的 `canvas` 配置；版本 10 把此前的内置身份迁移为中性默认值，同时保留部署方自定义内容；版本 11 新增创作输入框氛围渐变色；版本 12 新增光晕大小、水平位置和上下位置；版本 13 新增显示开关与强度，并把作用域扩展为完整创作首屏区域。读取旧 JSON 时未知字段由标准解码忽略，管理员下次保存后旧字段自然消失。

## 3. 固定视觉系统

`web/src/styles/globals.css` 是自研组件语义变量的唯一事实源，`web/src/lib/app-theme.ts` 固定提供经典黑白的 Ant Design 映射。亮色和暗色由用户主题偏好切换，不从外观接口读取圆角、动效、阴影或全站主题色，也不向根节点注入皮肤变量。外观接口只提供创作首屏背景氛围层的开关、强度、颜色、缩放和位置，由固定 CSS 渐变与模糊规则渲染，不参与控件状态和主题 token。

## 4. 首屏与品牌一致性

`index.html` 保持中性标题和无品牌 Logo。`main.tsx` 在加载 React 应用前请求 `/api/public/appearance`，完成品牌与 metadata 归一化后再渲染；请求失败时使用内置默认。自定义视频没有自定义封面时不加载内置海报。

运行时品牌投影覆盖登录、注册、找回密码、邮件、工作区、管理端、导出与诊断，以及浏览器 title、description、keywords、Open Graph、Twitter Card、theme-color、favicon 与 canonical。`theme-color` 固定为经典亮色 `#ffffff` 或经典暗色 `#0a0a0a`。

## 5. 后台交互与验收

后台“站点及外观”保留品牌识别、创作首屏氛围、登录页内容与媒体、SEO 信息、首页收尾与备案，并提供 Canvas Agent 配置。所有调整先形成页面草稿，只有点击“保存修改”才上传新资源并提交；离开、刷新覆盖和恢复默认继续使用未保存保护，恢复默认不删除已上传资源。

- 自定义站点名应同步进入公共页面、邮件和继承型发件人名称。
- 单 Logo 与双 Logo 在亮暗模式下正确复用或切换，外框开关立即生效。
- SEO、版权与备案经前后端校验、持久化和公开投影完整生效。
- Canvas Agent 文案、内置光球头像和 Live2D 资源在画布入口、欢迎区与面板中保持一致。
- 公开接口不返回内部资源 ID、对象路径、存储凭据或任何皮肤字段。
- 登录页、工作台、画布和管理后台在亮暗模式下保持经典黑白样式。
