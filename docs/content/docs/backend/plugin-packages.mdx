插件清单是构建合同。直接维护 `plugin-packages/<插件 ID>/manifest.json`、README 和接口文档；第一方只分发 `.yingce-plugin`，导入仍支持 `.yingce-plugin` 与 `.lovwow-plugin`。第三方原有身份和格式保留，不能通过全仓替换修改供应商 ID、协议标识或持久化键。

`generate-catalog.mjs` 只为缺失的目录创建初始文件，已有维护中的清单不会被旧模板覆盖。`embed-documentation.mjs` 从真实清单更新完整接口文档，替换旧生成标记，再嵌入清单；不把文档中的模板当作运行合同。

## 构建与校验

在包含 Go、Node 和 zip 的构建环境运行：

```sh
sh plugin-packages/build-packages.sh
```

构建先同步文档，再从当前源码生成支付执行文件并打包。默认覆盖 Linux、macOS、Windows 的 amd64/arm64；`PAYMENT_PLUGIN_GOOS` 与 `PAYMENT_PLUGIN_GOARCH` 可明确选择单个平台，`PAYMENT_PLUGIN_CGO_ENABLED` 默认为 0。宿主机默认执行文件采用 Linux amd64；平台文件的名称包含真实目标信息，不能只复制改名来冒充另一平台。

所有分发包的 SHA-256 写入 `plugin-packages/SHA256SUMS`。在对应目录核对：

```sh
cd plugin-packages
sha256sum -c SHA256SUMS
```

只更新支付包可使用 `--payments-only`。包内声明、README、接口文档和执行文件必须与目录一致；构建不会创建业务渠道、模型、价格或用户数据。

## 新增协议与既有配置

本轮新增的 11 项协议作为可选能力提供，首次注册默认关闭；已有插件的启停状态保留。管理员启用插件并配置渠道、模型和价格后，才会形成可用业务能力，不因此开启新增工作台入口。

图片参数以插件声明为边界，渠道只能收紧范围。分辨率、质量和像素尺寸分开处理；旧配置按具体协议进行可证明等价的投影，报价、价格条件、任务准入和执行同步使用。未知或冲突值不静默重置默认值，不把未配置的价格自动匹配到相邻规格，也不重算历史订单。

OpenAI 参考图优先使用可用对象存储签名地址；本地内联必须关联本人已上传资源，并校验归属、状态、图片类型及大小。签名失败不代表内联已获准，仍须能读取并通过相同检查。遮罩的既有内联路径保留，但实际内容同样受类型和大小限制。

AutoDL 当前分发只提供视频。旧音频与 IndexTTS2 配置数据保留，对应模型和任务不再获准执行，不自动迁到其他供应商；已有未完成任务的资金、退款与恢复行为须在升级前演练。

## A6API SVG 矢量图

`plugin-packages/a6api-svg/` 提供独立可上传协议，插件 ID 为 `a6api-svg`，Provider ID 为 `a6api-svg-image`。内置 A6API 不能被上传覆盖，因此管理员应安装独立包，再复制并显式切换指定模型的协议，核对尺寸、质量、单张数量、价格与公开模型关联。原 PNG、透明 PNG 和既有 GIF 模型继续使用原协议。

新协议只请求 `/images/generations`，固定 `output_format=svg`、`n=1`，拒绝参考图、蒙版编辑与其他数量；不发送流式、渐进图片、压缩和透明背景参数。支持 URL 与 Base64 结果。A6API 文档没有承诺所有模型或商家支持 SVG，必须用实际精确模型 ID 和目标线路确认；插件安装或本地测试通过不证明上游可用。

本协议依赖配套宿主后端的 SVG 支持，不能仅把包上传到旧后端。宿主验证完整静态 SVG XML、元素、本地引用与有效尺寸；拒绝脚本、事件、外部资源、动画和内嵌位图。通过校验后保留原始字节，以 `image/svg+xml`、`.svg` 与实际宽高保存，沿用资源归属、生成配额、任务保存恢复及附件/sandbox 分发策略。URL 返回必须提供正确 MIME；忽略格式参数而返回位图会明确失败，不把 PNG/GIF 改后缀当作矢量图，不自动重提收费生成。

前端已有 SVG 下载扩展名映射，本次不新增矢量路径编辑器或位图转矢量功能。真实模型生成、浏览器预览、对象存储与实际用量计费须另行验收；本次不修改报价、账务或数据表。

## GrsAI GPT Image SVG 专用插件

`plugin-packages/grsai-svg/` 是独立声明式协议源码，插件 ID 为 `grsai-svg` 1.0.0，Provider ID 为 `grsai-svg-image`。可上传包为 `grsai-svg.yingce-plugin`；下载交付 ZIP 内使用带版本的 `grsai-svg-1.0.0.yingce-plugin` 文件名。包内根目录直接包含 manifest、README 和接口文档，文档由现有嵌入脚本针对本插件同步。

协议固定请求 `POST /v1/api/generate`，使用 `gpt-image-2.6`、`outputFormat=svg`、`quality=auto`、`replyType=async`。支持文档列出的比例和 1K 尺寸及可选参考图 URL/Base64；单次一张，拒绝蒙版、其他模型、格式、质量和未声明尺寸。使用 `GET /v1/api/result?id=<任务ID>` 分离回查，读取 `results[].url`；违规映射为失败。恢复只查询原任务，不声明取消或幂等创建支持。

默认全球节点为 `https://grsaiapi.com`，可在渠道改用国内节点 `https://grsai.dakka.com.cn`。管理员安装启用后须单独配置渠道、精确模型 ID、动态参数、价格和公开模型关联，并关闭蒙版支持。GrsAI 文档限定 SVG 仅适用于 `gpt-image-2.6`，任务出最终结果后查询有效期为两小时。

本插件依赖配套宿主 SVG 校验和保存能力，不能仅上传到旧版后端。宿主检查完整静态 SVG XML、有效尺寸、元素及本地引用，拒绝脚本、事件、外部资源、动画和内嵌位图；通过后按 `image/svg+xml`、`.svg` 和实际宽高保留原始字节。沿用资源归属、生成配额、保存恢复及附件/sandbox 分发；忽略 SVG 参数而返回位图时明确失败。不提供位图转矢量或矢量路径编辑，不修改 API、数据表、账务和既有协议。真实上游生成、浏览器与对象存储验收见待测试文档。

## 支付插件升级

新单使用启用的支付渠道；暂停只停止新单，旧单仍可查单、关单和验签。存在仍占库存或限购名额的未确认订单时，升级和卸载受到保护，同版本替换为不同内容也不能绕过检查。

启动引导更新已安装支付包前，同样检查未决订单：有未决订单保留旧包，没有未决订单才更新；无法核对时延期更新。相同内容的重装不触发替换。可先暂停新单，结清存量后手动升级。

模型协议专项、支付库测试和平台构建只能证明相应范围。数据库事务、实际启动、跨进程安装/下单并发、渠道回调与生产升级仍需单独验收。
