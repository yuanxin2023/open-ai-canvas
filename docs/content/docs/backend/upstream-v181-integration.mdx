# v1.8.1 本地整合

官方来源固定为 v1.8.1 的 `8611fc0eb0dadf30f62db7b3e196a63301c68b28`，本地起点为 `114a9e19`。本页记录自有 `v1.8.2` 的整合合同；正式发布以 GitHub Release 及匹配镜像为准，发布不代表真实业务和生产升级已完成验收。

## 计费与支付

文本 Token 加入分时与上下文规则：建单时固定上海时间时段，结算按包含缓存命中和写入的真实总输入 Token 选档。仍直接使用微积分，不接多币种、汇率和分组倍率；价格输入保留两位小数。账单固定候选规则，退款恢复沿用快照和本地账务保护。

参考视频计费按官方方案：模型开关控制是否计费，价格档分别保存参考视频售价与成本；按秒任务以后端实测时长计费，测不出则拒绝提交，视频处理任务的源视频不重复计费。旧纯 Token 视频模型自动开启并回填现价，含按秒档的模型保持关闭；报价、换线路和流水保存一致口径。

支付保留本站人民币、促销、库存和返利合同，接入官方 RPC 业务错误识别并重建多平台插件。关单采用官方确认与复查：查单异常返回失败并保留待支付；关单失败后再查一次，已付款则入账，只有连续确认订单不存在才按渠道不存在关单。渠道确认信息继续进入本地库存和关单记录合同。

## 技能、素材与权限

舍弃本地技能管理及整分类、单技能两层可用性控制，采用官方列表、上架/下架、信息编辑和文件工作台。接口继续要求 `admin.platform.skills`；同步保留管理员编辑，历史技能 ID、内容、版本和安装引用不清空。旧可用性表不再参与访问判定，不重写其历史迁移。

方舟素材采用官方真人、虚拟、版权素材组、审核与授权，管理操作仍要求 `admin.settings.ark_private_assets`。姿势库采用官方导入、同步、浏览和选用，新增独立权限 `admin.content.pose_library`；受限管理员须明确获授，用户选用后复制为自己的资源。

灵感大厅采用官方每日推荐与上游中文提示词同步，管理操作要求 `admin.content.inspirations`。个人提示词保留独立入口、用户隔离及原有保存合同；大厅写操作等待保存结果再提示成功。

## 界面取舍

- 采用官方侧栏与账号菜单，品牌名称读取本站配置，保留个人提示词入口。
- 首页采用官方模式卡及修复，保留本地桌面对话侧栏和手机历史抽屉。
- 设置采用官方用途分组、方舟素材和提醒偏好，保留账号安全、订单、积分流水栏目。
- 画布工具条、引用菜单、素材、反馈和任务列表整体采用官方界面和交互，不恢复本地斜杠快捷命令。
- 功能开放保留本地双栏和逐项确认，接入官方新功能与依赖提示；服务商模型目录向导继续不提供。

发布版本为自有 `v1.8.2`，沿用自有正式 Release 更新源及独立 Agent 部署。统一套餐中心保留订单与流水，更新日志仅在管理员后台显示，设置侧栏仅显示分类名称。旧扩容接口已移除，Web 与 Backend 必须匹配更新。检查及人工验收边界见[待测试](/docs/progress/pending-test)；完整讨论记录在仓库 `docs/plans/upstream-v1.8.1-conflicts.md`。
