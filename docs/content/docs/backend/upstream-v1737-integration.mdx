# v1.7.3.7 本地整合

本地版本以已整合 v1.7.3.5 的代码为基础，合并官方正式标签 v1.7.3.7。以下取舍已经确认；实现和自动检查不代表真实部署及业务验收完成。

## 界面与创作

- 保留本地导航、提示词入口、手机适配、创作历史、余额与容量展示，接入中文、英文、法文、德文、日文和韩文。切换语言保存设备偏好并刷新页面；保留界面中的自定义文案由 `web/src/i18n/messages/local.ts` 提供六种语言。
- 电商 Agent 使用五步流程与交付区，阶段模型使用通用模型下拉；移除小夜悬浮助手、设置、接口与功能开关。
- 登录、注册和找回密码共用面板，后台 `loginMode=modal|page` 决定普通登录入口。工作区进入登录流程前继续保存草稿；普通注册保留邮箱优先与可选邀请码，首个管理员仍可填写用户名。
- 保留后台功能开放双栏和逐项确认。依赖未开启时仍显示子项、说明依赖并禁用切换；保留额外业务开关及服务端管理员细分权限。
- 预演台采用官方演员 Y 高度规则；演员可以站上桌面或台阶，地下部分被拉回地面，不再保留冲突的旧导演专门处理。
- 页面渲染与悬停、空闲预取共用组件实例；保留本地客服、提示词、邀请、管理员权限、模型选择与报价边界。

## 积分与支付

文本 Token 售价、成本价和账单快照增加缓存写入单价；请求明细区分缓存命中与缓存写入。API 中新增 `cacheWriteTokenPriceMicrocredits`、`cacheWritePriceMicrocredits`、`cacheWriteTokens` 等字段。输入总量包括命中和写入，普通输入计费排除这两部分；预授权需要覆盖输入与缓存写入价格中较高者。旧价格档新增字段默认零，不重算历史账单。

保留本地积分计价、退款与恢复、报价快照及请求配额，不接入官方多币种、分组倍率或汇率。价格输入和显示保持本地精度；新缓存写入输入同样使用两位小数规则。账户余额、人民币订单、优惠及邀请奖励继续使用原合同。

易支付接入兼容的 `submit.php` 跳转等修复，使用本地人民币下单、关单与对账流程。没有 USD/CNY 汇率设置，也不增加支付实收换汇列。原虎皮椒与易支付是独立插件，不能把 Git 的二进制相似度匹配当成插件身份变更。

## 反馈、资源与插件

反馈采用官方提交、列表、答复及归档合同，接口仍通过 `http` 解包标准信封。移除本地反馈 requestId 幂等、反馈版本头及专用附件读取合同；后台服务继续要求 `admin.users.feedbacks`。反馈附件 JSON 纳入资源引用扫描，后台采用管理员资源接口预览。诊断可取消附带，前端移除地址查询参数、片段与画布标识。历史迁移与现有数据保留，不回写或清空旧附件。

插件清单与安装包统一采用官方 `yingce.plugin/v1|v2` 和 `.yingce-plugin`。同步转换清单、文档、运行时、测试和包内容，保留已有插件 ID 与本地独立插件。即梦按成功码 `10000` 判断，Novita 读取实际任务与视频字段，NewAPI 保留上游失败原因；易支付原生载荷必须与最终源码和各平台安装包匹配。

在线业务更新源继续使用自有仓库的完整正式 Release；本轮源码合并不改变发布来源，不会发布、推送、部署或执行 Host Updater。

## 数据迁移与验收

本地 Schema 1–103 的编号、名称、校验和及已应用时间保持原样。104 新增方舟真人认证会话、素材组与素材表；105 追加缓存写入价格和用量列。官方编号 80–82 不能直接覆盖本地同号迁移。

隔离迁移验证应覆盖 103 → 105、重复执行、旧账本不变和积分余额不变；也应确认没有接入被排除的汇率字段。真实数据库升级必须另行备份、副本演练和核对，本轮不执行。

SQLite 和隔离 PostgreSQL 已验证追加迁移、重复执行、旧账本和积分余额不变。数据库测试只使用虚构账号、临时 schema 与临时存储；不连接现有业务库。

预演台录制从编码器 `start` 事件后计时，避免首次编码器初始化超过短镜头时长而生成空视频。真实 Chrome E2E 已覆盖短片解码、取消录制、深度图、模型失败重试、上下文恢复和保存失败保护。

最终检查使用 `bun scripts/verify-before-push.mjs --base 6150cb15`，并补充受影响的计费、支付、资源、认证和迁移专项验证。真实模型生成、实际支付、第三方 H5 认证以及完整界面验收仍需使用对应环境完成。
