# GrsAI GPT Image · SVG 矢量图 1.0.0

独立协议插件 `grsai-svg`，Provider ID 为 `grsai-svg-image`。固定使用 `gpt-image-2.6` 请求 SVG，支持文字和可选参考图，不覆盖已有图片协议。

## 安装和使用

1. 先确认宿主后端包含本项目当前的 SVG 校验、任务保存和原文件下载支持。旧版宿主不能只靠安装插件补齐 SVG 保存能力。
2. 解压交付 ZIP，在后台插件管理上传 `grsai-svg-1.0.0.yingce-plugin`，启用插件。若宿主已随源码构建内置同 ID 插件，直接启用内置项；项目禁止上传覆盖内置插件。
3. 在渠道中选择「GrsAI GPT Image · SVG 矢量图」，配置 GrsAI API Key 和地址：全球节点 `https://grsaiapi.com` 或国内节点 `https://grsai.dakka.com.cn`。
4. 新建或复制一个模型，上游模型 ID 必须填写 `gpt-image-2.6`。显示名称可自定义；不要填写 `gpt_image-2.6`、flare 或 sunburst。
5. 核对动态参数、价格、公开模型关联及参考图权限；模型参考图配置须关闭蒙版支持。尺寸默认 1024x1024，质量 auto，单张生成，输出 SVG。
6. 刷新前台后选择该模型，描述图标、Logo 或插画，可附参考图。生成结束后下载原文件得到 .svg，可交给矢量编辑软件编辑。

## 行为和边界

- 固定发送 `outputFormat: "svg"`、`replyType: "async"`；不使用 OpenAI 的 `output_format` 字段。不提供 PNG/GIF 切换。
- 沿用宿主任务轮询和保存恢复；不声明上游幂等创建或取消接口，不自动切换模型或重提收费生成。
- GrsAI 文档说明任务出最终结果后仅可查询两小时，应及时保存作品。上游原图地址过期后，插件不能恢复已无法下载的文件。
- 结果读取 `results[].url`，下载受宿主出站限制。宿主要求正确 SVG MIME 和合法静态 SVG 内容，保留原始字节、尺寸和 .svg 扩展名。
- 上游返回 PNG/GIF、无效 XML、脚本、事件、外部资源、动画或内嵌位图时会失败；此插件不提供位图转矢量，也不把位图改后缀伪装成 SVG。
- 原文件沿用宿主附件/sandbox 分发与资源归属校验；不提供矢量路径编辑器，不放宽普通文件上传限制。
- 插件不包含真实密钥，不创建渠道、模型或价格，不修改账务和历史订单。
- 本地校验使用模拟上游和临时目录；未调用真实收费模型。实际线路的参考图效果、SVG 复杂度、预览、对象存储及计费仍需验收。
